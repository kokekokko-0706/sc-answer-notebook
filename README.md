# SC答案ノート（改訂版）

情報処理安全確保支援士試験の午後・科目Bの記述答案練習用Webアプリです。

## 試験形式の扱い
- 令和5年度秋期以降：統合後の午後（2026年度の名称は科目B）。大問は問1〜問4、4問から2問を選択する形式。
- 令和5年度春期以前：旧形式の午後Ⅰ・午後Ⅱを分けて選択。
- 科目A（旧午前Ⅰ・午前Ⅱ）は対象外です。

## 機能
- 年度・実施回、試験区分、大問の選択肢を年度に応じて切り替え
- 設問追加、答案入力、文字数カウント、文字数上限の入力
- 答案の保存・編集・削除、絞り込み、JSONバックアップ
- IPA公式解答例・採点講評を含めたChatGPT向け採点依頼文の作成

## 現時点の制限
- IPAの問題文・公式解答・採点講評を自動取得する機能は未実装です。公式資料は手動で貼り付けてください。
- 設問ごとの正確な字数制限は問題によって異なるため、現時点では自動設定していません。設問の指示を確認して入力してください。
- AI採点はアプリ内で自動実行せず、採点依頼文をChatGPTに貼り付ける方式です。
- 答案はブラウザ内に保存され、端末間同期はありません。定期的にバックアップしてください。
