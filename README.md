# SC答案ノート

情報処理安全確保支援士試験の答案を入力・保存し、ChatGPTに採点を依頼するための個人用Webアプリです。

## 現在の機能
- 年度・試験区分・問題番号の選択
- 設問を追加して記述答案を入力
- 文字数カウントと文字数上限の目安表示
- ブラウザ内（LocalStorage）への保存、編集、削除
- 年度・試験区分で保存答案を絞り込み
- JSONバックアップの書き出し・読み込み
- 設問文・公式解答例・採点講評を含めた「採点依頼文」の作成
- ChatGPTを開いて、作成した依頼文を貼り付ける運用

## 重要な制限
- IPAの過去問、公式解答、採点講評を自動取得する機能はまだありません。必要な資料は手動で貼り付けてください。
- AI採点はアプリ内で自動実行しません。採点依頼文をコピーしてChatGPTに貼り付けてください。
- 保存先は使っているブラウザのLocalStorageです。別端末との同期はありません。定期的にバックアップしてください。
- APIキーや答案の秘密情報を公開リポジトリに置かないでください。

## GitHub Pagesで公開する
1. リポジトリのルートに `index.html` と `README.md` をアップロードします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Build and deployment** の **Deploy from a branch** を選択します。
4. Branchを `main`、フォルダを `/(root)` にして保存します。
5. 表示されたURLをiPhoneのSafariで開き、共有メニューから「ホーム画面に追加」を選びます。

## プライバシー
GitHub Pagesで公開すると、ページのHTML/JavaScriptは公開されます。答案の保存データは通常リポジトリには送信されず、そのブラウザ内に保存されます。ただし共有端末の利用やブラウザデータの消去には注意してください。
