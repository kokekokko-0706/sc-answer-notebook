# SC答案ノート v03

## この版で追加したUI
- 科目Aを含めず、午後・科目Bの記述練習に絞った画面
- 年度、旧形式／統合形式、大問の選択
- 設問ごとの答案欄、文字数カウント、上限入力
- 解答例・採点講評の表示を切り替えるチェックボックス
- 答案・解答例・採点講評をまとめた採点依頼文をワンクリックでコピー
- ローカル保存とJSONバックアップ

## 重要な未実装項目
この版はUIの試作です。IPAの各年度PDFを解析して、実際の解答用紙と同じ設問・字数上限を自動登録する機能はまだありません。公式解答例・採点講評もアプリに内蔵していません。欄に貼り付けた内容をチェックボックスで隠す／表示する仕組みです。採点自体はChatGPTで行います。
IPAの公式資料は以下から確認してください：
https://www.ipa.go.jp/shiken/mondai-kaiotu/2025r07.html

公開前に実機でテストしてください。答案はブラウザのLocalStorageに保存され、端末間同期はありません。
